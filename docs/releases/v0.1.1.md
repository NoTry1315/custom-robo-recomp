# Custom Robo Recomp v0.1.1 (source only)

Bug-fix release of the static recompilation of *Custom Robo* (GameCube, USA, GXCE01) for the
New Nintendo 3DS.

**This release contains no game and no prebuilt `.3dsx`.** A build contains code translated
from the game's `main.dol`, so no build is published here. You build your own from your own
legally obtained disc; see the
[build and installation guide](../../README.detailed.md#build).

## Fixed

- **Story text boxes no longer break.** A box could lose its first letters, show the rest
  with even spacing and never finish, so A did nothing and the event stopped (for example in
  `snr_t_06` and Harry's "Now you see what she has to go through..." box).

  Cause: the game builds a texture object (GXTexObj) on its stack and compares all of its
  bytes with earlier ones to number the sprites of a text box. Our hand-written replacements
  for the SDK's `GXInitTexObj` functions did not clear the object and left some fields
  unwritten, so leftover stack bytes decided whether two identical textures matched, and the
  body text ended up sharing the name tag's number.

  Fix: `GXInitTexObj`, `GXInitTexObjCI`, `GXInitTexObjLOD` and
  `TPLGetGXTexObjFromPalette(CI)` are now translated from the game's own `main.dol` like the
  rest of its code, so every byte is what the SDK writes. Details:
  [recomp_unknowns.md](../../docs/recomp_unknowns.md) "GXTexObj bytes and the story text boxes".

  Checked with Citra replays (the broken event now finishes; 2-v-2, battle, campaign and boot
  replays give the same frames as v0.1.0, with no measurable speed change) and on a New 3DS
  (hardware run 58: same route as Citra, the box completes and the event finishes).

Performance is unchanged from v0.1.0.

## Known problems

- 2-v-2 battles and stereoscopic scenes do not yet hold 60 fps.
- Some graphics are missing: EFB-to-texture copies, specular highlights; widescreen leaves
  some 2D at the 4:3 edges.
- In Citra only, the dark background behind dialogue text is sometimes missing; the 3DS
  draws it.
- SD-card stalls can still disturb music at the start of a song.

Full list: [Known problems](../../README.detailed.md#known-problems).
