# custom-robo-recomp

Static recompilation of Custom Robo (GameCube) for the New 3DS. The game's
own code is translated from your disc's main.dol; this repo holds only the
translator and the 3DS runtime. No game files are included -- bring your own
disc.

Status: phase 2 (translator; gen/ compiles for 3DS with empty SDK stubs). See CLAUDE.md for the plan.
